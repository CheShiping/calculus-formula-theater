# Oil® (oiloil.org) 设计审查报告

> 审查日期：2026-08-09
> 目的：作为「面容整理」项目重构的视觉参考

---

## 一、整体气质

**关键词：白纸感 / 工程师手记 / 极简 / 教学型**

- 整页像一张**白纸 + 淡淡的网格线**，像工程笔记本/草图纸
- 没有重阴影、没有渐变、没有玻璃拟态、没有浮光
- 信息密度低，留白大量，靠**字号差**制造层级
- 每个项目都是一个「可交互的演示」（hover 演示、弹簧动画、毛玻璃开关）
- 视觉上是 **「工程师作品集」** 而非「品牌官网」——强调 show, not tell

**第一印象**：清爽、克制、有手作温度、内容是主角、装饰退到背景

---

## 二、配色系统（Design Tokens）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#FFFFFF` | 页面背景（纯白） |
| `--text` | `#1A1A1A` | 主文字 / 标题（近黑而非纯黑） |
| `--text-muted` | `#555555` | 副文字 / 段落描述 |
| `--text-inactive` | `#B8B8B8` | 未选中 tab / 占位符 |
| `--text-deep` | `#18181B` | footer 标签（zinc-900） |
| `--border` | `#E8E8E8` | 卡片边框 / 分隔线 |
| `--grid-line` | `rgba(0,0,0,0.03)` | 背景网格线 |

**关键观察**：
- **几乎没有强调色**。整站不靠颜色制造焦点，靠**字号、留白、位置**
- 唯一可见的彩色是 demo 中的 mini 插画（橙色小狗、黄色圆点）
- 黑/灰三级就够了：纯黑 → 深灰 → 浅灰 → 极浅灰
- 暖色倾向：footer 用 zinc 系（`#18181B`），不是纯黑

## 三、字体系统

```
font-family: "Helvetica Neue", -apple-system, "PingFang SC", "Noto Sans SC", sans-serif;
```

**字号层级**（注意：标题字号巨大，靠字号差形成视觉冲击力）：

| 层级 | 字号 | 字重 | 用途 |
|---|---|---|---|
| H1 Hero | **140px** | 700 | 主标题 "Oil® makes things." |
| Tab/导航 | **48px** | 700 | 顶部分类 tab |
| H3 产品名 | **40px** | 800 | Wolfcha / Text-Well 等产品标题 |
| 正文 | 15px | 400 | 卡片描述文字，line-height 1.95 |
| 演示文字 | 13.5px | 400 | 演示区文字，line-height 2.5（更松） |
| Footer/标签 | 16px | 400 | 版权 / 导航文字 |

**字体注意点**：
- 用系统字体栈（Helvetica Neue → PingFang SC → Noto Sans SC），不依赖 webfont
- 行高比常规松（1.95~2.5），让文字呼吸感强
- 不用斜体做强调，用 **`<b>` `<i>`** 配合句中红笔改错的视觉

## 四、布局与栅格

### 4.1 网格背景

```
.bg-grid {
  position: fixed;
  inset: 0;
  background:
    linear-gradient(rgba(0,0,0,0.03) 1px, transparent 0) repeat scroll 0 0 / 32px 32px,
    linear-gradient(90deg, rgba(0,0,0,0.03) 1px, transparent 0) repeat scroll 0 0 / 32px 32px;
  pointer-events: none;
  z-index: 0;
}
```

- **32px × 32px** 网格，线条 3% 不透明
- 固定定位铺满全屏，不随滚动
- **`pointer-events: none`** 不阻挡交互

### 4.2 主内容容器

- 居中布局，最大宽度 ~1200px
- 上下分区，每区一个独立大圆角卡片（border-radius 20px）
- 卡片之间用大间距（gap 约 40-60px）分隔
- 内容左对齐，左对齐到网格

### 4.3 卡片规范

```
.card {
  background: #FFFFFF;
  border: 1px solid #E8E8E8;
  border-radius: 20px;
  padding: 22px 26px;
  box-shadow: none;
}
```

- **20px 圆角** —— 比较大但不夸张
- 1px 细边框，不用阴影
- 内边距 22px × 26px（不对称，更亲和）

## 五、组件与交互

### 5.1 顶部导航

- 左：`OIL®` 品牌（® 标在右上角）
- 右：GitHub 链接 + 图标
- 极简，不放 menu icon

### 5.2 Tab 分类

- 字号 48px（巨大），未选中 `#B8B8B8`，选中 `#1A1A1A`
- 选中状态只靠**颜色变深**，没有下划线、底色、边框
- 横向排列，间距约 30px

### 5.3 产品卡片布局

每张卡片是 `horizontal flex`：
- 左侧预览区（占 60%）
- 右侧文字区（占 40%）
- 文字区顶部：H3 产品名（40px, 800）
- 中部：描述句（15px, 灰）
- 底部：`进入游戏 →` 调用链接

### 5.4 演示区（关键设计）

每个术语演示都是「**先告诉你，再让你摸**」：
- 顶部：术语名 + 别名 + 引号注解
- 中部：可交互 demo
- 底部：操作提示

例如「悬停 Hover」demo：
- 文案解释 → 三个按钮（不同 hover 行为）→ 提示语

### 5.5 Footer 链接列表

- 6 个链接，编号 01~06
- 每个链接：序号 + 平台名 + 账号/邮箱 + → 箭头
- 横向排列，每条占 1/6 宽度

## 六、视觉细节（必须保留）

### 6.1 网格不是装饰，是基准

所有元素**对齐到 32px 网格**，这是整站克制感的来源。

### 6.2 插画风格

- 黑白线稿 + 局部上色（橙色小狗）
- 不追求精致，**像便签纸上的速写**
- 给页面注入「手作」温度

### 6.3 引号用法

每段描述前面用 **左上引号 `「`** 或 **左上引号 `"`**，感觉像在引述别人说的话。

### 6.4 行内格式

- 改正错字时用 **红色笔删除** + 上下文替换（Text-Well demo）
- 关键字用 `<b>` 加粗
- 中英文混排自然，不刻意对齐

### 6.5 动画

- 弹性回弹（spring overshoot）
- 卡片 hover 浮起 + 变色
- 毛玻璃 backdrop-filter blur 演示
- 都是**功能性动画**，不是装饰

## 七、不能照搬的反面清单（避免 AI 模板化）

| 不要做 | 原因 |
|---|---|
| ❌ 纯黑底 + 浮光球 | oiloil 是纯白底 |
| ❌ 玻璃拟态卡片 | oiloil 用纯白 + 细边框 |
| ❌ 渐变背景 | 油油站没有任何渐变 |
| ❌ 鲜艳强调色 | 整站只有黑灰白 |
| ❌ 大投影 | 卡片只有 1px 边框 |
| ❌ Emoji 装饰 | 用真实插画 |
| ❌ Jones Stack 字体 | 用系统字体栈 |
| ❌ 动效堆砌 | 动画只服务于"教学" |

## 八、重构「面容整理」的迁移建议

### 8.1 保留的当前优点

- Linear 紧凑风（圆角 8px 等）
- 配色克制（暖橙 #DA7756 + 金 #E8C268）
- 公式中心化设计

### 8.2 引入 oiloil 元素

| 油油站元素 | 面容整理应用 |
|---|---|
| 32px 网格背景 | index.html + review.html 背景叠网格 |
| 巨型 hero 标题 | index.html 头部用 80-120px 标题 |
| 20px 圆角卡片 | 改用 20px 替代当前 8px |
| 1px 浅灰边框 | 替代当前阴影 |
| 大字号导航 tab | 分类筛选改成 48px 巨大 tab |
| 演示式交互 | 翻卡前展示「这是什么公式」 |
| 系统字体栈 | 改用 Helvetica Neue → PingFang SC |
| 网格背景叠加 | 公式卡背后有淡淡的网格 |

### 8.3 保留面容整理特性

- 暖橙+金配色（这是面容整理的辨识度）
- KaTeX 公式渲染
- Swiper 卡片轮播
- 6 章分类 + 翻卡复习

### 8.4 合并目标

**「工程师笔记本」+「暖色学习卡片」** = 既有 oiloil 的克制工程感，又有面容整理的温暖学习感
