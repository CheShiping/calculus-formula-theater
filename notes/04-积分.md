# 积分

## 一、定义

$$
\int f(x) \, dx = F(x) + C \quad (F'(x) = f(x))
$$

- **不定积分** = 一族函数（+C），是导数的逆运算
- **定积分** = 曲线下面积（牛顿-莱布尼茨公式）

> **记忆锚点**：积分 = 导数的逆运算。基本积分公式就是导数公式倒过来看。

---

## 二、常见积分公式（11 条）

### 2.1 常数 & 幂函数

| 序号 | 积分 | 结果 | 说明 |
|------|------|------|------|
| (1) | $\displaystyle\int k \, dx$ | $kx + c$ | 导数 (kx)'=k 的逆运算 |
| (2) | $\displaystyle\int x^\mu \, dx$ | $\dfrac{x^{\mu+1}}{\mu+1} + c$ | 注意 μ≠-1 |
| (3) | $\displaystyle\int \frac{dx}{x}$ | $\ln\|x\| + c$ | μ=-1 的特例，**绝对值不能丢** |

### 2.2 指数函数

| 序号 | 积分 | 结果 | 说明 |
|------|------|------|------|
| (4) | $\displaystyle\int a^x \, dx$ | $\dfrac{a^x}{\ln a} + c$ | 导数 (a^x/ln a)'=a^x 的逆运算 |
| (5) | $\displaystyle\int e^x \, dx$ | $e^x + c$ | ⭐ eˣ 积分还是 eˣ，最特殊 |

### 2.3 三角函数

| 序号 | 积分 | 结果 | 说明 |
|------|------|------|------|
| (6) | $\displaystyle\int \cos x \, dx$ | $\sin x + c$ | 导数 (sin x)'=cos x 的逆运算 |
| (7) | $\displaystyle\int \sin x \, dx$ | $-\cos x + c$ | 导数 (-cos x)'=sin x 的逆运算 |
| (8) | $\displaystyle\int \frac{1}{\cos^2 x} \, dx = \int \sec^2 x \, dx$ | $\tan x + c$ | 高频，导数 (tan x)'=sec²x 的逆运算 |
| (9) | $\displaystyle\int \frac{1}{\sin^2 x} \, dx = \int \csc^2 x \, dx$ | $-\cot x + c$ | 导数 (-cot x)'=csc²x 的逆运算 |

### 2.4 反三角型

| 序号 | 积分 | 结果 | 说明 |
|------|------|------|------|
| (10) | $\displaystyle\int \frac{1}{1+x^2} \, dx$ | $\arctan x + c$ | 导数 (arctan x)'=1/(1+x²) 的逆运算 |
| (11) | $\displaystyle\int \frac{1}{\sqrt{1-x^2}} \, dx$ | $\arcsin x + c$ | 导数 (arcsin x)'=1/√(1-x²) 的逆运算 |

> **导数↔积分联动记忆**：⭐⭐⭐ 最高效记忆法——导数公式倒过来 = 积分公式。记住 $(\tan x)'=\sec^2 x$ → 就知道 $\int \sec^2 x \, dx = \tan x + C$。记住一边等于记住两边。

## 三、特殊积分公式（8 条）

这些不是基本导数的直接逆运算，需通过换元或分部积分推导，建议直接记结果。

### 3.1 三角函数特殊积分

| 积分 | 结果 | 说明 |
|------|------|------|
| $\displaystyle\int \tan x \, dx$ | $-\ln\|\cos x\| + c$ | 等价于 $\ln\|\sec x\|+C$ |
| $\displaystyle\int \cot x \, dx$ | $\ln\|\sin x\| + c$ | 等价于 $-\ln\|\csc x\|+C$ |
| $\displaystyle\int \sec x \, dx$ | $\ln\|\sec x + \tan x\| + c$ | ⭐ 高频考点 |
| $\displaystyle\int \csc x \, dx$ | $\ln\|\csc x - \cot x\| + c$ | 与 ∫sec x 配对记忆 |

### 3.2 含 a² 的积分

| 积分 | 结果 | 说明 |
|------|------|------|
| $\displaystyle\int \frac{1}{a^2+x^2} \, dx$ | $\dfrac{1}{a} \arctan \dfrac{x}{a} + c$ | 口诀：a 在前面用 arctan |
| $\displaystyle\int \frac{1}{x^2-a^2} \, dx$ | $\dfrac{1}{2a} \ln\left\|\dfrac{x-a}{x+a}\right\| + c$ | 注意：分母是 x²-a²（减号） |
| $\displaystyle\int \frac{1}{\sqrt{a^2-x^2}} \, dx$ | $\arcsin \dfrac{x}{a} + c$ | 口诀：a 在前面用 arcsin |
| $\displaystyle\int \frac{1}{\sqrt{x^2 \pm a^2}} \, dx$ | $\ln\left\|x + \sqrt{x^2 \pm a^2}\right\| + c$ | ⭐ 记忆口诀：塞进去弹出来 |

> **含 a² 积分记忆口诀**：「塞进去，弹出来，a 在前面用 arc」
> - 含 √(x²±a²) → $\ln\|x+\sqrt{...}\|$（塞进去弹出来）
> - 含 a²+x² → $\frac{1}{a}\arctan\frac{x}{a}$（a 在前面用 arc）
> - 含 √(a²-x²) → $\arcsin\frac{x}{a}$（a 在前面用 arc）
