# 多元函数积分学（二重积分）

> 本章是「多元函数积分学」，只讲**二重积分**（二元函数在平面区域 $D$ 上的积分）。它把第四章**一元函数积分学**里的「定积分」从「一条线上的积分」推广到「一个面上的积分」，是**定积分的长高**：被积函数从一元的 $f(x)$ 变成二元的 $f(x,y)$，积分区间从「数轴上的 $\[a,b]$」变成「平面上的闭区域 $D$」。**不是新知识，而是旧知识升了一维**——定积分的所有技巧（偶倍奇零、点火公式、$\frac14$ 圆面积）在这里全部沿用。传统教材常把它单独成章，本笔记专门把**每一处都与一元定积分对标**，让你联动记忆、触类旁通。

***

## 〇、为什么它是「定积分的长高」【联动总纲】

先建立一张「升维对照表」，全章反复回看：

| 一元定积分（第四章）                              | 二重积分（本章）                                                      | 对应关系          |
| --------------------------------------- | ------------------------------------------------------------- | ------------- |
| 对象 $y=f(x)$，一条曲线                        | 对象 $z=f(x,y)$，一张曲面                                            | 维数从 1 → 2     |
| 意义 $\int\_a^b f(x),dx$＝一块面积             | 意义 $\iint\_D f(x,y),d\sigma$＝以 $D$ 为底、$z=f(x,y)$ 为顶的**体积**    | **面积 → 体积**   |
| 积分区间 $x\in\[a,b]$                       | 积分区域 $D$（平面上的点集）                                              | 一条线段 → 一个面    |
| 写成 $\int\_a^b f(x),dx$                  | 写成 $\iint\_D f(x,y),dx,dy$                                    | 一个积分号 → 两个积分号 |
| 累次积分 $\int\_a^b\Big(\int \cdots\Big)dx$ | 累次积分 $\int\_a^b dx\int\_{\varphi\_1(x)}^{\varphi\_2(x)} f,dy$ | 先积内层、再积外层     |
| 技巧：偶倍奇零、点火公式、$\frac14$ 圆面积              | **同样适用**（本质还是定积分）                                             | 技巧原封不动照搬      |

> 💡 **一句话记忆**：**一元定积分算「一块面积」，二重积分算「一堆面积叠起来的体积」**；而「叠起来」的每一步，都还是做定积分。你只要会算定积分，再会「画区域、定上下限、决定先积谁」，二重积分就全会了。

### 什么是「先求面积，再堆叠成体积」？

二重积分 $\iint\_D f(x,y),d\sigma$ 想求的是：以平面区域 $D$ 为底，以曲面 $z=f(x,y)$ 为顶的「曲顶柱体」体积。

$$
\boxed{;\iint\_D f(x,y),dx,dy=\int\_a^b dx\int\_{\varphi\_1(x)}^{\varphi\_2(x)}f(x,y),dy;}
$$

它的思路和定积分求面积一模一样的「先切条、再累加」：

1. **先把区域切成一沓「面片」**：固定一个方向，把 $D$ 切成一摞平行薄片；
2. **每个面片先算「截面面积」**：在面片里沿另一方向做一次**定积分**，得到一片「薄面积」；
3. **再把一沓面片叠起来**：对「薄面积」再做一次**定积分**，就是体积。

一句话：**二重积分 = 先积一次（得截面），再积一次（堆体积），两次都是定积分。**

## 一、二重积分的性质（数学语言）

设 $f(x,y),\ g(x,y)$ 都在有界闭区域 $D$ 上可积，$S$ 为区域 $D$ 的面积，$m,\ M$ 分别为 $f$ 在 $D$ 上的最小、最大值。则：

| 性质                | 数学语言                                                                                                 | 记忆提示                   |             |   |           |                 |
| ----------------- | ---------------------------------------------------------------------------------------------------- | ---------------------- | ----------- | - | --------- | --------------- |
| **线性性**（常数可提、可拆和） | $\displaystyle\iint\_D \[\alpha f+\beta g],d\sigma=\alpha\iint\_D f,d\sigma+\beta\iint\_D g,d\sigma$ | 和定积分一致，常数出积分号          |             |   |           |                 |
| **区域可加性**（拆区域）    | $D=D\_1\cup D\_2$（$D\_1\cap D\_2$ 无公共内点） ⟹ $\displaystyle\iint\_D f=\iint\_{D\_1}f+\iint\_{D\_2}f$   | **拆绝对值、拆分段函数就靠它**      |             |   |           |                 |
| **保号性 / 不等式**     | 若 $f(x,y)\le g(x,y)$ 于 $D$，则 $\displaystyle\iint\_D f\le\iint\_D g$                                  | 大曲线体积大                 |             |   |           |                 |
| **绝对值不等式**        | $\displaystyle\Big                                                                                   | \iint\_D f,d\sigma\Big | \le\iint\_D | f | ,d\sigma$ | 先积分论大小 ≤ 绝对值再积分 |
| **估值定理**          | $\displaystyle mS\le\iint\_D f,d\sigma\le MS$                                                        | 被大中小夹住                 |             |   |           |                 |
| **中值定理**          | 存在 $(\xi,\eta)\in D$ 使 $\displaystyle\iint\_D f,d\sigma=f(\xi,\eta),S$                               | 定积分中值定理的二维版            |             |   |           |                 |
| **被积函数为 1**       | $\displaystyle\iint\_D 1,d\sigma=S$（区域面积）                                                            | **算面积时最常用**            |             |   |           |                 |

> ⚠️ **联动警示**：二重积分的性质几乎是一元定积分性质的「逐条升级」，唯一要特别记住的是**区域可加性**——它是「拆分区域」「去掉绝对值」的数学依据，专升本解答题第一步常常就是拆区域。

## 二、直角坐标系中的计算

### 2.1 两类积分次序：X 型 与 Y 型

> **联动（对累次积分）**：定积分写成 $\int\_a^b f(x)dx$ 只有一种顺序；二重积分因为有两个变量，**谁先积、谁后积**有两种选择——这就是 X 型 / Y 型。**本质都是「先积内层（把另一个变量当常数），再积外层」。**

**X 型区域**（先积 $y$，后积 $x$）：沿 $x$ 方向「由一条竖线扫成一个面片，再把一沓面片沿 $y$ 方向堆叠」。

```
D = { (x,y) | a ≤ x ≤ b , φ₁(x) ≤ y ≤ φ₂(x) }

  ∬₀ f dxdy = ∫ₐᵇ dx ∫_{φ₁(x)}^{φ₂(x)} f(x,y) dy
```

> 【配图：X 型区域图】固定一个 $x$，画竖线穿过区域，竖线两端落在下边界 $y=\varphi\_1(x)$ 和上边界 $y=\varphi\_2(x)$ 上 → 得一条「线」；把这条线沿 $x$ 方向移动扫出来，就是「**线到面**」$S$；再把这些面片沿 $y$ 方向叠加起来，就是体积。

**口诀（X 型）**：\*\*竖线上下为 $y$ 限，$x$ 从两边常数到常数。\*\*先对 $y$ 积分，把 $x$ 当常数。

**Y 型区域**（先积 $x$，后积 $y$）：沿 $y$ 方向「由一条横线扫成一个面片，再把一沓面片沿 $x$ 方向堆叠」。

```
D = { (x,y) | α ≤ y ≤ β , ψ₁(y) ≤ x ≤ ψ₂(y) }

  ∬₀ f dxdy = ∫_{α}^{β} dy ∫_{ψ₁(y)}^{ψ₂(y)} f(x,y) dx
```

> 【配图：Y 型区域图】固定一个 $y$，画横线穿过区域，横线两端落在左边界 $x=\psi\_1(y)$ 和右边界 $x=\psi\_2(y)$ 上 → 得一条「线」；把这条线沿 $y$ 方向移动扫出来，就是「**线到面**」$S$；再把这些面片沿 $x$ 方向叠加起来，就是体积。

**口诀（Y 型）**：\*\*横线左右为 $x$ 限，$y$ 从两边常数到常数。\*\*先对 $x$ 积分，把 $y$ 当常数。

> 💡 **联动记忆**：X 型「竖着切」、Y 型「横着切」。**先积谁，谁就是「竖线/横线穿过去的那个变量」**；最后积的变量，它的上下限一定是常数。

***

#### 例题（X 型 · 专升本难度）

**题**：计算 $\displaystyle\iint\_D (x^2+y),dx,dy$，其中 $D$ 由曲线 $y=x^2$ 与 $y=\sqrt{x}$ 所围成的闭区域。

**解**：① 画图（两曲线交于 $(0,0)$ 与 $(1,1)$），区域为 $0\le x\le1$，$x^2\le y\le\sqrt{x}$（X 型）。

$$
\iint\_D (x^2+y)dx,dy
\=\int\_0^1 dx\int\_{x^2}^{\sqrt{x}}(x^2+y),dy
\=\int\_0^1\Big\[x^2y+\frac12y^2\Big]\_{x^2}^{\sqrt{x}}dx
$$

$$
\=\int\_0^1\big(x^{\frac52}+\frac12x-\frac32x^4\big)dx
\=\Big\[\frac27x^{\frac72}+\frac14x^2-\frac3{10}x^5\Big]\_0^1
\=\frac27+\frac14-\frac3{10}=\frac{33}{140}.
$$

> 💡 **提示**：这题若反过来用 Y 型要把 $y=x^2$ 改写 $x=\pm\sqrt y$、$y=\sqrt{x}$ 改写 $x=y^2$，会**拆成两块**更麻烦。**先画图、看哪个方向不需要拆区域，就选哪个型。**

***

#### 例题（Y 型 · 专升本难度）

**题**：计算 $\displaystyle\iint\_D x^2y,dx,dy$，其中 $D$ 由直线 $y=\sqrt{x}$、曲线 $xy=1$ 与直线 $x=2$ 所围成的闭区域。

**解**：① 画图：$xy=1\Rightarrow y=\frac1x$，与 $y=\sqrt x$ 交于 $(1,1)$。区域 $1\le x\le2$，$\dfrac1x\le y\le\sqrt{x}$（X 型即可，直接算）：

$$
\iint\_D x^2y,dx,dy
\=\int\_1^2 dx\int\_{\frac1x}^{\sqrt x}x^2y,dy
\=\int\_1^2\Big\[\frac12x^2y^2\Big]\_{\frac1x}^{\sqrt x}dx
\=\int\_1^2\frac12\Big(x^3-\frac1x\Big)dx
$$

$$
\=\frac12\Big\[\frac14x^4-\ln x\Big]\_1^2
\=\frac12\Big(4-\ln2-\frac14\Big)
\=\frac{15}{8}-\frac12\ln2.
$$

> 💡 **提示**：本题按区域用 X 型就可直接算；示范「Y 型先积 $x$」时，同理把 $x$ 的范围写成 $\psi\_1(y)\le x\le \psi\_2(y)$ 即可。**做题先画图，选更简单的型。**

### 2.2 画图求曲线、直线所围成的闭区域面积

> **联动（对定积分求面积）**：一元求 $y=f(x)$ 与直线围的面积是 $\displaystyle\int\_a^b\big\[f(x)-g(x)\big]dx$；二重积分求面积其实**更简单**——令被积函数为 $1$，面积 $=\displaystyle\iint\_D 1,dx,dy=S$（就是性质里的「被积函数为 1」）。

**画图三招（不会画区域就做不了题）：**

1. **认形**：看到 $\ln x$、$e^x$、直线、二次函数，先用**标准图形**在脑子里/草稿上打底；

   - 直线 $y=ax+b$：两点连线；

   - 二次 $y=x^2$：开口向上抛物线；

   - 指数 $y=e^x$、对数 $y=\ln x$：单调曲线；
2. **判断位置与交点**：联立方程求**交点坐标**——这些交点就是**新的积分上下限**；
3. **定上下限**：交点 ± 给定直线/曲线，校验区域边界，写出两种型的上下限。

> 💡 **联动警示**：\*\*专升本考题给的区域基本都是「指数 / 对数 / 直线 / 二次函数」两两围成。\*\*要是连这些标准图形的样子都记不牢，题目第一步「画图」就画不出来，后面全白搭。这一章的记忆重点，其实在第一章的常见函数图像上。

**标准图形速记：**

| 类型  | 标准形                    | 关键特征                 |
| --- | ---------------------- | -------------------- |
| 直线  | $y=ax+b$               | 两点定线                 |
| 抛物线 | $y=x^2,\ y=ax^2+bx+c$  | 开口方向由二次项系数正负决定       |
| 指数  | $y=e^x,\ y=a^x\ (a>1)$ | 过 $(0,1)$，单调上升       |
| 对数  | $y=\ln x$              | 过 $(1,0)$，单调上升，$x>0$ |
| 反比例 | $y=\dfrac1x$           | 过 $(1,1)$，两支曲线       |

#### 例题 · 专升本难度（画图求面积）

**题**：求由曲线 $y=x^2$ 与直线 $y=2x$ 所围成的平面图形的面积。

**解**：① 画图：$y=x^2$ 开口向上，$y=2x$ 过原点；联立 $x^2=2x\Rightarrow x(x-2)=0$，交点 $(0,0)$、$(2,2)$，区域内下方是 $x^2$，上方是 $2x$。

② 令被积函数为 $1$，用 X 型，$0\le x\le2$，$x^2\le y\le 2x$：

$$
S=\iint\_D1,dx,dy=\int\_0^2 dx\int\_{x^2}^{2x}dy=\int\_0^2(2x-x^2)dx
\=\Big\[x^2-\frac13x^3\Big]\_0^2=4-\frac83=\frac43.
$$

> 💡 **联动记忆**：这和一元定积分 $\int\_0^2(2x-x^2)dx=\frac43$ 一模一样——**求面积时，二重积分只是把一元定积分「写长」了**（多套了一个 $\int dy$）。

***

#### 需要拆分的区域 + 绝对值（例题）

> 有的区域**不能只用一种 X 型或 Y 型一次写到底**，必须**按曲线拆成几块**再分别积——这就是「**拆分区域**」。最常见的拆分触发条件是：**被积函数含绝对值**（在 $|f|=0$ 分界线的两侧正负不同），或区域本身不规则。

**做法步骤（拆绝对值）：**

1. **令绝对值内的式子 $=0$**，解出「分界线」；
2. 画图，用分界线把 $D$ 拆成 $D\_1,D\_2,\dots$；
3. 在每个子区域上「去绝对值」（该处为正则保留，为负则加负号）；
4. 用**区域可加性**加总：
   $$
   \iint\_D |f(x,y)|,dx,dy=\iint\_{D\_1} f,dx,dy+\iint\_{D\_2}(-f),dx,dy+\cdots
   $$

> 【配图：正方形临虚线 xy＝1 拆两块】

***

#### 例题（绝对值 · 专升本难度）

**题**：计算 $\displaystyle\iint\_D \big|x\big|,dx,dy$，其中 $D:,x^2+y^2\le1$（单位圆）。

**解**：① 令 $|x|=0$ 得分界线 $x=0$（$y$ 轴），把单位圆拆成左、右两半。
② 右半 $x\ge0$：$|x|=x$；左半 $x\le0$：$|x|=-x$。由对称性，两半相等：
$$
\iint\_D |x|,dx,dy=2\iint\_{D\_{\text{右}}}x,dx,dy.
$$
③ 右半圆（$0\le x\le1,\ -\sqrt{1-x^2}\le y\le\sqrt{1-x^2}$）：
$$
2\int\_0^1 dx\int\_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}}x,dy
\=2\int\_0^1 x\cdot2\sqrt{1-x^2},dx
\=4\cdot\frac13=\frac43.
$$

> 💡 **联动记忆**：`偶倍奇零`在这里「暗度陈仓」——$|x|$ 是偶函数，积分等于**对称一侧（右半）的两倍**，拆区域后只需算一半。

> **更常见的拆分尖子题（专升本模型）**：$\displaystyle\iint\_D |xy-1|,dx,dy$，$D:{0\le x\le2,\ 0\le y\le2}$。
> **解**：令 $xy=1$，用双曲线 $y=\dfrac1x$ 把正方形拆成 $D\_1$（$xy\ge1$）与 $D\_2$（$xy\le1$）：
> $$
> \iint\_D|xy-1|=\iint\_{D\_1}(xy-1)+\iint\_{D\_2}(1-xy)=\frac32+\ln2.
> $$
> （算的过程就是按上面的「去绝对值 + 拆区域加总」，难度达压轴水平，**能把前面破产的同学拉开分**。）

### 2.3 用圆、偶倍奇零、点火公式、$\frac14$ 圆面积简化

> **联动（对定积分技巧）**：二重积分的**本质还是定积分**，所以定积分攒下的技巧**一个都不用丢，全部照搬**：
>
> - **偶倍奇零**（对称性）→ 见第四章 §对称性；
>
> - **点火公式（华里士公式）** $\displaystyle\int\_0^{\frac\pi2}\sin^n x,dx=\int\_0^{\frac\pi2}\cos^n x,dx$ → 处理三角函数定积分；
>
> - **$\frac14$ 圆面积** $\displaystyle\int\_0^a\sqrt{a^2-x^2},dx=\frac{\pi a^2}{4}$ → 遇到根号圆直接用「面积」秒算。

**例题（专升本难度 · 用 $\frac14$ 圆面积）**：计算 $\displaystyle\iint\_D \sqrt{1-x^2},dx,dy$，$D:{0\le x\le1,\ 0\le y\le1}$。

**解**：
$$
\iint\_D\sqrt{1-x^2},dx,dy=\int\_0^1\Big(\int\_0^1 dy\Big)\sqrt{1-x^2},dx=\int\_0^1\sqrt{1-x^2},dx=\frac\pi4.
$$

> 💡 **提示**：$\int\_0^1\sqrt{1-x^2}dx$ 正是**第一象限 $\frac14$ 单位圆面积** $=\frac\pi4$，直接写答案，不用去算换元。

## 三、交换积分次序

### 3.1 一般题型：根据上下限确定 → 交换次数

> **联动（对累次积分）**：有时按给定次序积分很麻烦甚至积不出来，那就**换一种次序**。方法就三步：
>
> 1. **画图**：由原积分的上下限复原出积分区域 $D$；
> 2. **找区域**：只有符合原上下限范围的点才是区域里的点（一坨或两坨都有可能）；
> 3. **换次序**：把先积 $y$ 后积 $x$ 换成先积 $x$ 后积 $y$（X 型 ↔ Y 型，互相转换），把原来画的图形「换一个角度看」。

**题型 1：上下限是确定数字的（一坨积分）**

#### 例题 · 专升本难度（交换次序）

**题**：交换 $I=\displaystyle\int\_0^1 dx\int\_{\sqrt{x}}^1 f(x,y),dy$ 的积分次序。

**解**：① 画图：原积分 $\begin{cases}x:0\to1\ y:\sqrt x\to1\end{cases}$，区域由 $y=\sqrt{x}$、$y=1$、$x=0$ 围成。
② 换次序看：$y$ 从 $0\to1$，固定 $y$，$x$ 从 $0$ 到 $x=y^2$（由 $y=\sqrt{x}$ 反解 $x=y^2$）：
$$
I=\int\_0^1 dy\int\_0^{y^2} f(x,y),dx.
$$

> 【配图：交换前后的区域与扫描方向对比】

**题型 2：上下限含变量的（拆成两坨积分）**

#### 例题 · 专升本难度（两坨积分交换）

**题**：交换 $I=\displaystyle\int\_0^1 dx\int\_x^{2-x} f(x,y),dy$ 的积分次序。

**解**：① 画图：$0\le x\le1$，$x\le y\le 2-x$。两边界 $y=x$ 与 $y=2-x$ 交于 $(1,1)$；区域为三角形 $(0,0),(1,1),(0,2)$。
② 换序要**拆成两坨**：因为 $0\le y\le2$，但 $x$ 的左右边界要按 $y$ 分段：

- 当 $0\le y\le1$：$x$ 从 $0$ 到 $x=y$（由 $y=x$）→ $D\_1$；

- 当 $1\le y\le2$：$x$ 从 $0$ 到 $x=2-y$（由 $y=2-x$）→ $D\_2$。
  $$
  I=\int\_0^1 dy\int\_0^y f,dx+\int\_1^2 dy\int\_0^{2-y}f,dx.
  $$

> 💡 **关键**：**一条边界线在两个区域分界点处往往要「分段反解」**。画图后盯住「拐点」$(1,1)$，就知道要在 $y=1$ 处拆。

***

### 3.2 特殊题型：只能固定用一种形状（积不出来的函数）

> 有些被积函数**积不出来**（没有初等原函数），但你只要**交换次序**，就能把积不出来的那个变量变到「后积」的位置（或变成外层常数）。
>
> **规律很直白**：**哪个变量单独出现在「积不出来」的函数里，就先积另一个变量，把这个难缠的变量放在最后积**。

| 只能看作 **X 型**（先积 $y$，把含 $x$ 的留到最后）                                                                         | 只能看作 **Y 型**（先积 $x$，把含 $y$ 的留到最后）                                                                         |
| --------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| $e^{x^2}$，$e^{-x^2}$，$\dfrac{\sin x}{x}$，$\dfrac{\cos x}{x}$，$\dfrac{\arctan x}{x}$，$\sin x^2$，$\cos x^2$ | $e^{y^2}$，$e^{-y^2}$，$\dfrac{\sin y}{y}$，$\dfrac{\cos y}{y}$，$\dfrac{\arctan y}{y}$，$\sin y^2$，$\cos y^2$ |

> 💡 **联动记忆**：**观察被积函数里「只含有哪一种变量」**。它只含 $x$，就先积 $y$（X 型），把它留到外层一次性处理，$\int e^{x^2}dx$ 之类就**不会再卡死你**——因为你根本不用积它本身，只交换一下次序它就被「整体带出去」了。

#### 例题 · 专升本经典（交换次序救出生天）

**题**：计算 $I=\displaystyle\int\_0^1 dx\int\_x^1 e^{-y^2},dy$。

**解**：① 被积函数只含 $y$（$e^{-y^2}$ 积不出来）→ 应该**先积 $x$（Y 型）**，把 $e^{-y^2}$ 留在外层当常数。
② 画图：区域 $0\le x\le1$，$x\le y\le1$（三角形：直线 $y=x$ 与 $y=1$ 围成）。换 Y 型：
$$
I=\int\_0^1 dy\int\_0^y e^{-y^2},dx=\int\_0^1 e^{-y^2}\cdot y,dy.
$$
③ 凑微分（内层 $\int\_0^y dx=y$）：
$$
I=\int\_0^1 y,e^{-y^2}dy=-\frac12 e^{-y^2}\Big|\_0^1=\frac12\Big(1-\frac1e\Big).
$$

> 💡 **真题启示**：这是专升本/考研必考的一道「交换次序」代表作。**看见 $e^{-y^2}$、$\dfrac{\sin y}{y}$ 这一类，第一反应就是「换次序，让难函数当常数被带出去」**。

## 四、普通对称性（奇偶性）

> **联动（对奇偶性）**：一元定积分有「偶倍奇零」$\int\_{-a}^a$（偶函数 2 倍、奇函数 0）；二重积分把它**推广到平面对称区域**上——**区域关于哪条轴对称，就看被积函数对哪个变量是奇是偶**。

**规则（普通对称性）：**

1. **$D$ 关于 $y$ 轴对称**（左右对称）：

   - 被积函数对 $x$ 为**偶**函数（$f(-x,y)=f(x,y)$）⟹ 积分 $=2$ 倍右半区域；

   - 被积函数对 $x$ 为**奇**函数（$f(-x,y)=-f(x,y)$）⟹ 积分 $=0$。
2. **$D$ 关于 $x$ 轴对称**（上下对称）：

   - 对 $y$ 为**偶**函数 ⟹ $2$ 倍上半区域；

   - 对 $y$ 为**奇**函数 ⟹ $0$。
3. **$D$ 关于 $x,y$ 轴都对称**（如圆、矩形以原点为中心）：

   - 对 $x,y$ 都为**偶** ⟹ $4$ 倍第一象限区域；

   - 对某个变量为**奇** ⟹ $0$。

> 口诀：**先看区域对称轴，再看被积函数奇偶；对轴的那一变量：偶数翻倍、奇数归零。**

#### 例题（对称性 · 专升本难度）

**题**：设 $D:\ x^2+y^2\le1$，求 $\displaystyle\iint\_D \left(x+xy^2\right)dx,dy$。

**解**：① 区域是单位圆，关于 $x$ 轴、$y$ 轴都对称。
② 拆开两项分别看：

- $\iint\_D x,dx,dy$：被积函数只有 $x$，关于 $y$ 轴为**奇函数**（$(-x)=-x$）⟹ $=0$；

- $\iint\_D xy^2,dx,dy$：对 $x$ 为奇（$(-x)y^2=-xy^2$）⟹ $=0$。
  $$
  \iint\_D\left(x+xy^2\right),dx,dy=0+0=0.
  $$

> 💡 **联动记忆**：**看到区域对称、被积函数「单独一个变量」或「含奇数次那个变量」时，别急着算——先想对称性**，多数直接归零，省一半时间。这就叫定积分的「偶倍奇零」在二重积分里的二维版。

## 五、极坐标系中的计算

### 5.1 直角 ⟷ 极坐标 的转换（三件套）

> **联动（对换元法）**：二重积分不止能用直角坐标算，还能用**极坐标**算（本质是「换元」）。遇到**圆 / 圆环 / 扇形**和**被积函数含 $x^2+y^2$** 时，极坐标往往一步出结果。

**核心转换式（必背，一个都不能漏）：**

$$
\boxed{;x=r\cos\theta,\qquad y=r\sin\theta,\qquad x^2+y^2=r^2,\qquad dx,dy=r,dr,d\theta; }
$$

> ⚠️ **联动作弊点（送命题）**：**$dx,dy$ 换成极坐标要乘 $r$（记作 $r,dr,d\theta$），这个 $r$ 最容易漏！** 漏了 $r$，结果直接错光。口诀：**`rdr`** **不分家，换元必带 $r$。**

**极坐标系中二重积分的形式：**

$$
\iint\_D f(x,y),dx,dy=\int\_\alpha^\beta d\theta\int\_{r\_1(\theta)}^{r\_2(\theta)}f\big(r\cos\theta,\ r\sin\theta\big),r,dr
$$

> 💡 **记忆提示**：专升本考试里基本都是 **$\theta$ 在前、$r$ 在后**（先积 $r$，$\theta$ 当常数；再积 $\theta$）。看见 $\int\_\alpha^\beta d\theta \int\_{r\_1}^{r\_2}\cdots r,dr$ 就是这个套路。

**换元做法三连：**

1. **根据题干画图**，判断区域是不是圆相关；
2. **定限**：$\theta$ 从几条射线到几条射线，$r$ 从内侧边界 $r\_1(\theta)$ 到外侧边界 $r\_2(\theta)$；
3. **套公式**：被积函数把 $x=r\cos\theta,\ y=r\sin\theta$ 代入，$dx,dy\to r,dr,d\theta$。

***

#### 例题 1（直角转极坐标 · 专升本难度）

**题**：计算 $\displaystyle\iint\_D \big(x^2+y^2\big)dx,dy$，其中 $D:\ x^2+y^2\le4$。

**解**：① 区域是圆、被积含 $x^2+y^2$ → 用极坐标。
② 极径 $r$：从 $0$ 到 $2$；极角 $\theta$：$0\to2\pi$（整圆）。
③
$$
\iint\_D(x^2+y^2)dx,dy=\int\_0^{2\pi}d\theta\int\_0^2 r^2\cdot r,dr
\=\int\_0^{2\pi}d\theta,\frac{r^4}{4}\Big|\_0^2
\=2\pi\cdot4=8\pi.
$$

***

#### 例题 2（极坐标转直角 · 专升本难度）

**题**：把 $\displaystyle\int\_0^{\frac\pi2}d\theta\int\_0^{1}f\big(r\cos\theta,r\sin\theta\big)r,dr$ 化为直角坐标下的累次积分。

**解**：① 这是第一象限「四分之一圆」：$\theta:0\to\frac\pi2$，$r:0\to1$ ⟹ 直角区域 $0\le x\le1$，$0\le y\le\sqrt{1-x^2}$。
②
$$
原式=\int\_0^1 dx\int\_0^{\sqrt{1-x^2}} f(x,y),dy.
$$

> 💡 **提示**：**极坐标能转直角、直角也能转极坐标**，互转的关键都在「画图定限」。本题示范的是逆方向转换。

***

### 5.2 圆的不同形式（化标准形 + sin/cos 上下限）

> 极坐标最常见的区域是**圆**，但圆有各种「变体」：上圆、右圆、扇形、环形。**上下限里出现 $\sin\theta,\ \cos\theta$ 的情况，说明圆的方程不是「以原点为圆心」的标准形，而是如 $x^2+y^2=2y$ 这类偏心圆——要先把它化成标准形再定限。**

**破题核心：**

1. **若圆的方程不是 $x^2+y^2=a^2$**（圆心不在原点），先配方化成标准形，如：
   $$
   x^2+y^2=2y\quad\Longrightarrow\quad x^2+(y-1)^2=1\quad(\text{圆心 }(0,1),\text{半径 }1).
   $$
2. 代极坐标 $x=r\cos\theta,\ y=r\sin\theta$ 定 $r$ 的上下限：
   $$
   x^2+y^2=2y\ \Longrightarrow\ r^2=2r\sin\theta\ \Longrightarrow\ r=2\sin\theta
   $$
   此时 $r$ 上限是 $2\sin\theta$（不再是个常数），$\theta$ 从 $0$ 到 $\pi$。

| 图形形态        | 直角坐标方程示例                | 化极坐标后的定限                                        |
| ----------- | ----------------------- | ----------------------------------------------- |
| **整圆**      | $x^2+y^2\le a^2$        | $0\le r\le a$，$0\le\theta\le2\pi$               |
| **上圆（上半圆）** | $y\ge0$                 | $0\le r\le a$，$0\le\theta\le\pi$                |
| **右圆（右半圆）** | $x\ge0$                 | $0\le r\le a$，$-\frac\pi2\le\theta\le\frac\pi2$ |
| **扇形**      | 极角受限                    | $\theta\_1\le\theta\le\theta\_2$，$0\le r\le a$  |
| **环形**      | $a^2\le x^2+y^2\le b^2$ | $a\le r\le b$，$0\le\theta\le2\pi$               |
| **偏心圆**     | $x^2+y^2=2y,\ 2x$ 等     | $r=2\sin\theta,\ 2\cos\theta$（化成标准形）            |

> 【配图：上圆 / 右圆 / 扇形 / 环形 四种区域 + 偏心圆极坐标】

***

#### 真题（环形 · 2008 河南专升本 第 41 题）

**题**：直角坐标系下二重积分 $\displaystyle\iint\_D f(x,y),dx,dy$（其中 $D$ 为环域 ${1\le x^2+y^2\le9}$）化为极坐标形式。

**解**：环域 $1\le r\le3$，整圈 $\theta:0\to2\pi$：
$$
\iint\_D f,dx,dy=\int\_0^{2\pi}d\theta\int\_1^3 f\big(r\cos\theta,\ r\sin\theta\big)r,dr.
$$

> **答案**：$\displaystyle\iint\_D f,dx,dy=\int\_0^{2\pi}d\theta\int\_1^3 f\big(r\cos\theta,r\sin\theta\big),r,dr$。

***

#### 例题（偏心圆 · 专升本难度）

**题**：计算 $\displaystyle\iint\_D x,dx,dy$，其中 $D:\ x^2+y^2\le2y$。

**解**：① 配方：$x^2+(y-1)^2\le1$——偏心圆，圆心 $(0,1)$，半径 $1$。
② 极坐标：$x^2+y^2=2y\Rightarrow r^2=2r\sin\theta\Rightarrow r=2\sin\theta$（$0\le\theta\le\pi$）。
③
$$
\iint\_D x,dx,dy=\int\_0^\pi d\theta\int\_0^{2\sin\theta}r\cos\theta\cdot r,dr
\=\int\_0^\pi \cos\theta,\frac{r^3}{3}\Big|\_0^{2\sin\theta}d\theta
\=\frac83\int\_0^\pi\cos\theta\sin^3\theta,d\theta=0.
$$
（$\cos\theta\sin^3\theta$ 在 $\[0,\pi]$ 上关于 $\theta=\frac\pi2$ 对称、为奇，故为 $0$。）几何上偏心圆的形心横坐标即圆心 $x=0$，故总面积为「半径乘形心」得 $I=0$，结果合理。

> 💡 **记忆提示**：看见圆的方程里出现单独的 $y$（或 $x$）项（如 $2y$），**一定是偏心圆**，先配方，再用 $r=2\sin\theta$（或 $2\cos\theta$）当上限。

***

### 5.3 含绝对值的极坐标系计算（冲刺 150 看）

> 🔭 这是**满分级压轴**内容，一般掌握 5.1、5.2 即可；目标是总分 150 的冲分选手再看这里。**极坐标里拆绝对值：先找 $r=$ 常数分界线（$x^2+y^2=r^2$），再用区域可加性拆环域。**

#### 例题（冲刺 · 极坐标绝对值）

**题**：计算 $\displaystyle\iint\_D \big|x^2+y^2-1\big|,dx,dy$，其中 $D:\ x^2+y^2\le4$。

**解**：① 令 $x^2+y^2-1=0$ 得分界线 $x^2+y^2=1$（$r=1$），把大圆拆成内圆 $(r\le1)$ 与外环 $(1\le r\le2)$ 两块。
② 内：$|r^2-1|=1-r^2\ (r\le1)$；外：$|r^2-1|=r^2-1\ (r\ge1)$。
③
$$
\iint\_D|x^2+y^2-1|=\int\_0^{2\pi}d\theta\int\_0^1(1-r^2)r,dr+\int\_0^{2\pi}d\theta\int\_1^2(r^2-1)r,dr
$$
$$
\=2\pi\Big\[\frac12-\frac14\Big]+2\pi\Big\[\Big(\frac{16}{4}-2\Big)-\Big(\frac14-\frac12\Big)\Big]
\=2\pi\cdot\frac14+2\pi\cdot\frac{25}{12}
\=\frac\pi2+\frac{25\pi}{6}=\frac{28\pi}{6}=\frac{14\pi}{3}.
$$

> 💡 **联动记忆**：极坐标里的绝对值，分界线就是「**等 $r$ 的圆**」。拆成内圆+外环，各自去掉绝对值再算，用的还是**区域可加性**——和直角坐标里「拆区域」是同一个道理，只是分界线从直线变成了圆。

## 七、核心记忆口诀汇总

1. **升维总纲**：一元定积分算面积，二重积分算体积；一切的每一步还是定积分。
2. **性质**：会拆区域的「区域可加性」最值钱——去绝对值、拆分段函数都靠它。
3. **X 型 / Y 型**：谁穿线先积谁，最后积的变量上下限是常数。
4. **画图**：认形（指数/对数/直线/二次）→ 求交点 → 定上下限；图绘不牢题做不了。
5. **求面积**：令被积函数为 $1$，$S=\iint\_D 1,dx,dy$。
6. **拆绝对值**：$|f|=0$ 画分界线，分界线一内一外加（区域可加性）。
7. **定积分技巧**：偶倍奇零、点火公式、$\frac14$ 圆面积——二重积分里照样秒算。
8. **交换次序**：画图找区域，拐点处拆两坨，换一种次序再来一遍。
9. **积不出来的函数**：**被积只含 $x$ 走 X 型，只含 $y$ 走 Y 型**——让难函数当常数被带出去。
10. **普通对称性**：对轴的那个变量，**偶数翻倍、奇数归零**。
11. **极坐标三件套**：$x=r\cos\theta,\ y=r\sin\theta,\ x^2+y^2=r^2$。
12. **极坐标面积元**：$dx,dy=r,dr,d\theta$——**`rdr`** **不分家，换元必带 $r$**。
13. **定限顺序**：$\theta$ 前 $r$ 后；$r$ 从内侧曲线到外侧曲线。
14. **偏心圆**：先配方化标准形，$r=2\sin\theta$（或 $2\cos\theta$）。
15. **极坐标绝对值（冲刺）**：$r=$ 常数画分界线，拆内圆 + 外环。
