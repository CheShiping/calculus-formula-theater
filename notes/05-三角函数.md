### 1.2 还需实记的值（15° = π/12）

$$
\sin 15° = \frac{\sqrt{6}-\sqrt{2}}{4} \quad \cos 15° = \frac{\sqrt{6}+\sqrt{2}}{4} \quad \tan 15° = 2-\sqrt{3}
$$

> **特殊值记忆规律**：sin 和 cos 在 0°~90° 的值只有 0, 1/2, √2/2, √3/2, 1 五个值，按角度递增排列。sin 从 0 到 1，cos 从 1 到 0。90°~180° 镜像对称。tan = sin/cos。15° 可用和差角公式 sin(45°-30°) 现场推导。

## 二、常见关系（倒数·转换·平方）

### 2.1 倒数与转换关系

$$
\begin{aligned}
\tan x \cdot \cot x &= 1 \\
\sin x \cdot \csc x &= 1 \implies \csc x = \frac{1}{\sin x} \\
\cos x \cdot \sec x &= 1 \implies \sec x = \frac{1}{\cos x} \\
\tan x &= \frac{\sin x}{\cos x} \\
\cot x &= \frac{\cos x}{\sin x}
\end{aligned}
$$

### 2.2 平方关系

$$
\begin{aligned}
\sin^2 x + \cos^2 x &= 1 \quad \text{（⭐ 根基公式）} \\
\tan^2 x &= \sec^2 x - 1 \quad \text{（等价于 } 1 + \tan^2 x = \sec^2 x\text{）} \\
\cot^2 x &= \csc^2 x - 1 \quad \text{（等价于 } 1 + \cot^2 x = \csc^2 x\text{）} \\
1 + \tan^2 x &= \sec^2 x = \frac{1}{\cos^2 x} \\
1 + \cot^2 x &= \csc^2 x = \frac{1}{\sin^2 x}
\end{aligned}
$$

> **一个公式衍生所有**：所有三角恒等式的根基只有一个：$\sin^2 x + \cos^2 x = 1$。两边除以 $\cos^2 x$ → $1 + \tan^2 x = \sec^2 x$；两边除以 $\sin^2 x$ → $1 + \cot^2 x = \csc^2 x$。再加上倒数关系和商数关系，全部恒等式都能推出来。

## 三、升幂缩角公式（二倍角）

二倍角公式将角度从 α 变为 2α（缩角），同时幂次升高（升幂）。cos2α 有三种等价形式，在积分降幂时极为有用。

$$
\begin{aligned}
\sin 2\alpha &= 2 \sin \alpha \cos \alpha \\
\cos 2\alpha &= \cos^2 \alpha - \sin^2 \alpha \quad \text{（① 原始形式：差平方）} \\
\cos 2\alpha &= 2\cos^2 \alpha - 1 \quad \text{（② 只含 cos²：消去 sin²）} \\
\cos 2\alpha &= 1 - 2\sin^2 \alpha \quad \text{（③ 只含 sin²：消去 cos²）}
\end{aligned}
$$

> **三种形式各有用途**：
> - ① 需要同时保留 sin 和 cos 时用 $\cos^2 - \sin^2$
> - ② 积分遇到 $\cos^2$ 时用 $2\cos^2 - 1$ 反解（降幂）
> - ③ 积分遇到 $\sin^2$ 时用 $1 - 2\sin^2$ 反解（降幂）

---

## 四、降幂扩角公式

降幂公式从二倍角余弦公式反解得到——把 cos2α 的公式倒过来解出 cos²α 和 sin²α。幂次降低（²→¹），角度扩大（α→2α）。

$$
\sin^2 x = \frac{1 - \cos 2x}{2} \quad \text{（由 } \cos 2x = 1-2\sin^2 x \text{ 反解）}
$$

$$
\cos^2 x = \frac{1 + \cos 2x}{2} \quad \text{（由 } \cos 2x = 2\cos^2 x - 1 \text{ 反解）}
$$

> **积分遇平方 → 先降幂**：⭐ 积分高频考点。遇到 $\sin^2 x$ 或 $\cos^2 x$ 没法直接积分，但降幂后变成 $\cos 2x$ 的形式，就能直接积分了。
>
> 标准套路：$\sin^2 x / \cos^2 x$ → 降幂 → $\int \cos 2x \, dx$ → $\frac{1}{2}\sin 2x + C$。降幂公式不是新公式，是二倍角公式的逆变形。

## 五、宇宙无敌最强六边形记忆法

将六个三角函数排成六边形，三条对角线代表倒数关系，三个阴影三角形代表平方关系——一张图打包所有基本恒等式。

### 5.1 六边形布局

```
      sin ——— cos
     /    \  /    \
   tan     \/     cot
     \     /\     /
      sec ——— csc
```

- 顶点（顺时针从正上）：tan → sin → cos → cot → csc → sec → tan
- 对角线（倒数）：sin↔csc, cos↔sec, tan↔cot
- 阴影三角形（平方）：
  - 顶部（sin, cos）→ $\sin^2 + \cos^2 = 1$
  - 左侧（tan, sec）→ $\tan^2 + 1 = \sec^2$
  - 右侧（cot, csc）→ $\cot^2 + 1 = \csc^2$

### 5.2 六边形三大规则

| 规则 | 内容 | 公式 |
|------|------|------|
| **规则一：倒数关系** | 对角线两端的函数互为倒数 | $\sin \cdot \csc = 1$，$\cos \cdot \sec = 1$，$\tan \cdot \cot = 1$ |
| **规则二：平方关系** | 三个阴影三角形各给出一个平方恒等式 | $\sin^2 + \cos^2 = 1$，$\tan^2 + 1 = \sec^2$，$1 + \cot^2 = \csc^2$ |
| **规则三：商数关系** | 顺时针方向，每个函数等于下一个除以再下一个 | $\tan = \frac{\sin}{\cos}$，$\cot = \frac{\cos}{\sin}$ |

### 5.3 导数与积分配对

| 函数 | 导数 | 积分 |
|------|------|------|
| $\tan x$ | $(\tan x)' = \sec^2 x$ | $\int \sec^2 x \, dx = \tan x + C$ |
| $\sec x$ | $(\sec x)' = \sec x \tan x$ | $\int \sec x \tan x \, dx = \sec x + C$ |
| $\cot x$ | $(\cot x)' = -\csc^2 x$ | $\int \csc^2 x \, dx = -\cot x + C$ |
| $\csc x$ | $(\csc x)' = -\csc x \cot x$ | $\int \csc x \cot x \, dx = -\csc x + C$ |

### 5.4 三角函数积分补充

$$
\begin{aligned}
\int \tan x \, dx &= \ln|\sec x + \tan x| + C = \ln|\sec x| + C \\
\int \sec x \, dx &= \ln|\sec x + \tan x| + C \\
\int \cot x \, dx &= -\ln|\csc x + \cot x| + C = \ln|\sin x| + C \\
\int \csc x \, dx &= -\ln|\csc x + \cot x| + C
\end{aligned}
$$

$$
\begin{aligned}
\int \sec^3 x \, dx &= \frac{1}{2} \left[\sec x \tan x + \ln|\sec x + \tan x|\right] + C \\
\int \csc^3 x \, dx &= -\frac{1}{2} \left[\csc x \cot x + \ln|\csc x + \cot x|\right] + C
\end{aligned}
$$

$$
\begin{aligned}
\int \frac{dx}{a^2 + x^2} &= \frac{1}{a} \arctan \frac{x}{a} + C \\
\int \frac{dx}{\sqrt{a^2-x^2}} &= \arcsin \frac{x}{a} + C \\
\int \frac{dx}{\sqrt{x^2 \pm a^2}} &= \ln\left|x + \sqrt{x^2 \pm a^2}\right| + C
\end{aligned}
$$

> **六边形记忆口诀**：中下二、下中下、导相乘、对对和。
> - 对角线 = 倒数（乘积为 1）
> - 阴影三角形 = 平方和
> - 导数与积分配对：tan 的导数 = sec²，反过来 ∫sec² = tan
> - ∫sec x 和 ∫tan x 的结果都含 $\ln|\sec x + \tan x|$，配对记忆效率最高
> - 含 a² 积分口诀：塞进去弹出来，a 在前面用 arc

## 六、诱导公式

诱导公式用于将任意角的三角函数转化为锐角三角函数。不用逐条背诵——记住八字口诀，所有诱导公式都能现场推导。

### 6.1 八字口诀

> **奇变偶不变，符号看象限**

- **奇变**：当 $k$ 为奇数时，$\sin(k \cdot \frac{\pi}{2} \pm \alpha)$ 函数名改变（sin↔cos，tan↔cot）
- **偶不变**：当 $k$ 为偶数时，$\sin(k \cdot \frac{\pi}{2} \pm \alpha)$ 函数名不变
- **符号看象限**：把 $\alpha$ 看作锐角，判断 $k \cdot \frac{\pi}{2} \pm \alpha$ 在第几象限，看原函数在该象限的正负

### 6.2 典型诱导公式

| 角度 | sin | cos | 说明 |
|------|-----|-----|------|
| $\pi - x$ | $\sin x$ | $-\cos x$ | 第二象限，sin 正 cos 负 |
| $\pi + x$ | $-\sin x$ | $-\cos x$ | 第三象限，sin 负 cos 负 |
| $-x$ | $-\sin x$ | $\cos x$ | sin 奇函数，cos 偶函数 |

> **八字口诀 = 全部诱导公式**：步骤：① 判断 $k$ 是奇还是偶 → 决定函数名变不变；② 把 $\alpha$ 当锐角，判断角在第几象限 → 决定正负号。
>
> 例如 $\sin(\frac{3\pi}{2} + x)$：$k=3$ 奇数 → 函数名变（sin→cos）；$\frac{3\pi}{2}+x$ 在第四象限 → sin 为负 → 结果 $= -\cos x$。
