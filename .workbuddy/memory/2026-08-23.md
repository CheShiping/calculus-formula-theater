## review 翻卡页 tab 居中（核心本次会话成果）
- 用户诉求：让 review 筛选 tab 栏与 index 详情页 `detail-tabs` 一致——**激活 tab 溢出可视区时自动回中**，且是**滑动内容**驱动，不是手动滑 bar 本身。
- 实现：
  1. `centerActiveChip(bar, activeChip)`（照抄 index `centerActiveDetailTab` 逻辑：rAF 双层、按 chip 中心点算目标 scrollLeft、越界 clamp 到 [0,maxScroll]）。
  2. `centerAllBars()`：同时让桌面 `#filterBar` 与移动端 `#mobileCategoryBar` 的激活 chip 居中。
  3. 桌面 `.filter-bar` 改为**仅 (min-width:641px) 生效**的单行横向滚动吸顶栏（`flex-wrap:nowrap`+`overflow-x:auto`+`position:sticky`+隐藏 scrollbar）；移动端保持原布局，tab 导航由 `.mobile-category-bar` 承担。
  4. 在 `initSwipeNavigation.handleSwipe`（滑动内容切章节）切换后调用 `centerAllBars()`。
- **踩坑/根因**：桌面 `.filter-bar` 原为 `flex-wrap:wrap`，永不横向溢出 → `maxScroll<=0` → 居中永不触发。必须改为 `nowrap` 单行滚动才有水平溢出可居中。
- **教训**：review 翻卡页的 tab 居中核心是「中心化逻辑要覆盖所有变更激活模块的路径」（点击 chip + 滑动内容），且不能只修 bar 本身。
