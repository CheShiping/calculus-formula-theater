## index.html 移动端顶部按钮隐藏
- 用户反馈：首页在移动端时，右上角"翻卡记忆 / GitHub / 主题切换"三个按钮遮挡下方章节标签。
- 解决：在 `@media (max-width: 768px)` 块内将 `.top-actions { display: none; }`，直接隐藏整个容器（取代之前的缩小样式）。
- 影响：移动端失去翻卡记忆/主题切换入口；用户接受此取舍。

## index.html 详情内容页：添加浮动标题栏 + 回到顶部按钮
- 浮动标题栏：已有的 `.detail-header`（`position: sticky; top: 0; z-index: 30`）在 #detail-view 滚动容器内固定在顶部，带返回按钮和章节 tabs。移动端生效（sticky 不受 flex-wrap 影响）。
