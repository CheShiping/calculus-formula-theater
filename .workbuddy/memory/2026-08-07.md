## 翻卡记忆 · 移动端 UX 改造（src/review.html）

### 需求
移动端分类栏始终平铺可滑动保持在顶部一栏；滑动到最下面时仍能切换分类；增加迅速回到顶部的浮动按钮（不遮挡公式记忆）；支持左右滑动切换分类。

### 实现要点
1. **粘性分类栏 `.mobile-category-bar`**
   - `position: fixed; top: 0.6rem`，z-index 150，移动端 `display: block`，桌面端 `display: none`
   - 横向溢出滚动，隐藏滚动条
   - 与侧边栏 `.filter-bar` 状态双向同步（`renderFilterBar` 末尾调用 `renderMobileCategoryBar`）
   - 移动端隐藏侧边栏的 `.filter-bar` 和对应 `.side-section-heading`，避免重复（用 `:has(+ .filter-bar)` 选择器）

2. **回到顶部按钮 `.back-to-top-btn`**
   - 右下角 `position: fixed; bottom: 1.5rem; right: 1.25rem`，z-index 160
   - 滚动 400px 后淡入（`.visible` class 控制 opacity + transform）
   - 平滑滚动：`window` 移动端 / `.main-stage` 桌面端

3. **左右滑动手势切换分类**
   - `touchstart` / `touchend` 事件挂在 `.main-stage`
   - 阈值：`SWIPE_THRESHOLD = 60`px 最小距离，`ANGLE_THRESHOLD = 1.5` 水平/垂直比率（防止误触发纵向滚动）
   - 边界保护：第一个分类禁止右滑，最后一个禁止左滑

### 第二轮调整
- 用户反馈：移动端只保留分类栏，去掉顶栏按钮（截图显示顶栏按钮占用顶部空间）
- `.top-bar` 在 ≤640px 时 `display: none`
- 分类栏升级为悬浮卡片样式：`left/right: 0.6rem`、`border-radius: 14px`、加深阴影

### CSS 单位经验
- 移动端分类栏高度约 52px → 侧边栏 `padding-top` 从 5rem 减到 3.75rem；主舞台 `padding-top: 3.5rem`
- 单位混用：rem 用于间距/字号，px 用于 1px hairline 边框
