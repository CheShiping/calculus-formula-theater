# 项目长期记忆（MEMORY.md）

## 笔记内容铁律（来自现有 notes/ 的通行惯例，务必遵守）
- **真题（⭐真题）必须有真实出处**：必须标注年份 + 地区/考试名称 + 题号，例如「2024 年四川专升本 · 第 1 题」「2023 年山东专升本高数（Ⅰ）· 第 1 题」。凡是随手编的普通例题，**只能叫「例题」**，严禁贴「真题」标签冒充历年考题。
- **⭐考点 / ⭐核心公式** 是对知识点的应试提示，不算真题，可正常使用。
- 放任何题目前，先翻现有 `notes/*.md` 对齐标注风格；拿不准是否为真实真题时，宁可标「例题」并提示用户补充出处，也不要自己编题号。

## 内容增量工作流（harness 已固化在 AGENTS.md §4）
1. 人工给初版要点 → 2. AI 按个性化要求润色成风格一致的笔记（notes/）→ 3. **等用户审核**（草稿先确认）→ 4. 增量加进 index.html → 5. `node scripts/extractFormulas.mjs` 自动同步 review.html。绝不动既有架构/设计/风格。

## 例题 / 真题 取材规则（2026-08-20 用户明确）
- **例题优先用真题**：给笔记配例题时，**先联网搜真实专升本真题**（带年份+地区+题号/文档名）；**实在搜不到真实真题时，才用自编「例题」**，且自编例题**要有一定难度**（避免过于幼稚），并明确标「例题」而非「真题」。
- 搜真题可靠来源：虞姐专升本真题分类、各省市专升本历年真题 PDF（人人文库/原创力文档/book118）、成信大/西华大学等院校模拟卷。
- 来源存证：每道 ⭐真题 都保留「年份+地区+题号/文档名」便于核对；无法核实出处的只标「例题」。

## 页面例题摆放铁律（2026-08-20 用户明确）
- **知识点与例题必须紧挨着放**：每个 `groupTitle` 知识点卡片之后，紧接放该知识点的 `exampleBox` 例题/真题（与第一章 buildFunctionDetail 的「知识点 → 例题 → 下一个知识点」结构一致）。**禁止**把整章例题集中堆到 tab 末尾单独开「例题与真题」区块——用户明确批评过这种做法（「不要成知识点是知识点，题是题了」）。
- 若用脚本挪移 exampleBox：插入锚点必须落在目标行**行首**（含 `${`），用 `lastIndexOf('\n', pos)+1`，否则会插进 `${groupTitle(...)}` 表达式中部把 `${` 拆开导致 JS 语法损坏（实测踩坑，已回滚重跑）。

## 翻卡页 LaTeX 已知坑（2026-08-20 用户反馈）
- **`review.html` 的 `toQuestionFormula(formula)` 不能用 `indexOf('=')` 截答案**——会撞到下标里的 `=`（如 `\sum_{k=1}^{n}` 的 `k=1`），导致前侧公式变成 `\sum_{k= ?`（主式被错误截断），触发 KaTeX `Expected '}'` 错，整张卡片显示红色错误。
- **修复**（已落到 `src/review.html` line 1523–）：改用 **bracket-depth 扫描**，跳过 `{...}` 与 `\X` 控制序列内部的 `=`，只把 depth=0 的「主等号」当分界点。
- **教训**：处理 LaTeX 字符串时，**别用 regex/朴素字符串操作假设 token 边界**——尤其 `=` 经常出现在花括号参数里。后续若加新公式出现类似「问侧变红」症状，先怀疑 `toQuestionFormula` / `toKatexSource`，再排查 KaTeX。
