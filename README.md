# 🎴 微积分与三角函数 · 公式体系联动记忆卡

> 一套用 **3D 卡片剧场 + 公式详情页** 重新组织的微积分与三角函数公式速查系统。  
> 不再是死记硬背的清单，而是「点开一张定义卡 → 进入完整公式网络」的联动记忆体验。

🌐 **在线演示**：[GitHub Pages 站点](https://shiping0001.github.io/calculus-formula-theater/)

---

## ✨ 项目亮点

### 🎬 沉浸式 3D 卡片剧场
- **Coverflow 3D 轮播** — 经典 Apple 风格的 3D 透视卡片，键盘 / 鼠标滚轮 / 点击三种导航方式
- **侧边栏叙事** — 左侧实时同步当前卡片的解说、要点提示、模块进度
- **荧光笔高亮动画** — 选中卡片的关键字段播放划线高亮，视觉聚焦

### 📚 五大模块，层级递进
五张定义卡分别通往对应的完整公式详情页：

| # | 模块 | 定义卡内容 | 详情页内容 |
|---|------|-----------|-----------|
| 01 | 总览 | 四大模块联动关系 | 全景导航，一键跳转任意模块 |
| 02 | 导数 | 定义 + 几何/物理意义 | **18 条导数公式**，按函数类型分组 |
| 03 | 微分 | dy = f'(x)dx | **16 条微分公式 + 3 类微分方程** |
| 04 | 积分 | ∫f(x)dx = F(x)+C | **常见 11 条 + 特殊 8 条**积分公式 |
| 05 | 三角函数 | sin²+cos²=1 | **6 大版块**：关系/特殊值/升降幂/六边形/诱导 |

### 🧠 结构化记忆，不是堆公式
每条公式都配有**记忆口诀**和**联动关系说明**，例如：

- **导数↔积分联动**：记住 (tan x)' = sec²x → 自动知道 ∫sec²x dx = tan x + C
- **微分不用背**：导数公式 × dx 就是微分公式
- **三角函数一个公式衍生所有**：sin²+cos²=1 → 推导倒数、商数、平方关系
- **宇宙无敌六边形记忆法**：一张图打包所有基本恒等式

### 🌗 深色 / 浅色双主题
- 右上角一键切换，主题选择持久化到 `localStorage`
- 首次访问自动跟随系统 `prefers-color-scheme`
- 所有组件（卡片、详情页、六边形 SVG、公式块）全部适配双主题

### 🎯 宇宙无敌最强六边形记忆法
三角函数详情页内置**交互式六边形 SVG**：
- 六个顶点 = 六个三角函数
- **对角线（黄色虚线）** = 倒数关系
- **三个阴影三角形** = 平方关系
- 鼠标悬停顶点放大发光

## 📖 内容覆盖

### 导数（18 条）
常数 & 幂函数 · 三角函数 · 指数 & 对数 · 反三角函数

### 微分（16 条 + 3 类方程）
微分公式 = 导数 × dx · 可分离变量方程 · 齐次方程 · 一阶线性非齐次方程

### 积分（11 + 8 条）
基本积分公式（导数逆运算） · 特殊积分（tan/sec/含 a² 型）

### 三角函数（6 大版块）
1. **关系与特殊值** — 0°~360° 特殊值表 + 15° 实记值
2. **常见关系** — 倒数 · 商数 · 平方
3. **升幂缩角** — 二倍角公式（cos2α 三种形式）
4. **降幂扩角** — sin²x / cos²x 降幂
5. **六边形记忆法** — 交互式 SVG + 三大规则
6. **诱导公式** — 「奇变偶不变，符号看象限」八字口诀

## 🎨 设计理念

- **暗色科技风**为主调，Apple 系配色（蓝/绿/黄/紫/红）
- **玻璃拟态**卡片 + `backdrop-filter` 模糊
- **渐进式讲解**：定义卡 → 详情页 → 分组公式 → 记忆口诀
- **联动记忆**代替孤立背诵：导数↔积分、二倍角↔降幂、平方关系↔六边形
